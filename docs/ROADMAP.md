# Roadmap

## Status at this release

- **DONE** — research, protocol specification, constitution, contract state
  model, semantic consensus path, adversarial Direct Mode suite, internal
  security review, Studionet deployment, all-read/write verification.
- **DONE** — one verified Polymarket Gamma adapter, backend boundaries,
  evidence-first compare UX, direct graph projection, wallet lifecycle states,
  responsive/accessibility/browser QA, production deployment.
- **ACTIVE** — observe provider completeness and Studio transaction UX in real
  usage; improve evidence display only when supported by real requirements.
- **PLANNED** — a second provider adapter after public API/legal/provenance and
  SSRF review; it is not currently claimed.
- **PLANNED** — Bradbury validation when current faucet/tooling availability and
  a safe deployment window support it.
- **PLANNED** — challenge/revalidation research only if a clear dispute and
  incentive model can be specified without weakening fail-safe semantics.
- **PLANNED** — agent/API pagination and indexing improvements if measured
  traffic outgrows the current single-process cache.

Tokens, staking, governance, liquidity, automatic transitive clusters, and
generic chatbot features are intentionally out of scope.
